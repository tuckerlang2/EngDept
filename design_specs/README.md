# design_specs/ — inbox

Drop a new design request JSON here (from the
[intake form](https://claude.ai/artifact/AT84wE1oMH41rXExXD9UBj)'s
"Copy to clipboard" output) as a new file, e.g.
`drone_frame_request.json`.

This is a holding area, not a finished project. Once a request turns
into real design work worth keeping, its JSON and outputs get moved
into `library/projects/<slug>/` instead — see `docs/library-spec.md`
and `docs/design-intake-form-spec.md` for the full workflow.

(This folder was empty before this README — git doesn't track empty
directories, which is why it didn't show up on GitHub even though it
was referenced in the docs.)
